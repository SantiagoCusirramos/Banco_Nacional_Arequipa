Mis tarjetas

Flujo del prototipo (usando puentes del frontend Next.js):
1) GET /api/tarjeta/cliente/{codCliente} → módulo Tarjetas lista las tarjetas del cliente.
2) GET /api/cuenta/consolidada/{codCliente} → interfaz INT-08 del módulo Cuentas devuelve las cuentas activas con saldos.
3) «Bloquear», tras confirmar: POST /api/tarjeta/{id}/bloqueo → módulo Tarjetas (por el Bus) deja la tarjeta BLOQUEADA.
Nota: Verificar titularidad no disponible en esta versión (requiere endpoint /api/tarjeta/{id}/verificar-titularidad).
